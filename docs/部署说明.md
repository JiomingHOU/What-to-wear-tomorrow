# 部署说明（把网址发给家人）

这份说明写给不懂代码的人。照着做，大约 10 分钟，你会得到一个 `https://` 开头的网址，家人在手机浏览器打开就能用。

---

## 先搞清楚一件事：为什么不能直接发文件

这个应用是"纯前端"的——所有照片都存在**打开它的那台手机**里，没有服务器。

所以它必须是"一个网址"，原因有三：

1. **每台手机的数据是独立的**。妈妈的手机和爸爸的手机各自存各自的衣橱，这正是"多档案 + 数据不离开手机"的设计。
2. **浏览器有硬限制**：直接双击 `index.html`（`file://` 开头）时，浏览器禁止页面读本地数据库、开相机、定位。应用会明确提示你改用网址访问。
3. **"添加到主屏幕"必须是 HTTPS**。没有 HTTPS，手机上装不了桌面图标，也没有全屏效果。

---

## 选一个免费的托管方案

| 方案 | 是否免费 | 要不要注册 | 难易 | 我的建议 |
|---|---|---|---|---|
| **GitHub Pages** | 免费 | 要一个 GitHub 账号 | 中等（网页上传，不用装 Git） | ✅ **推荐**，长期稳定，网址不会过期 |
| **Netlify Drop** | 免费 | 拖动上传时不用，想长期保留要注册 | 最简单（拖文件夹） | 想 5 分钟先试用就选这个 |
| Vercel / Cloudflare Pages | 免费 | 要注册 | 和 GitHub 差不多 | 备选 |
| 自己电脑开热点给家人用 | 免费 | 不用 | 简单 | ❌ 只能同一 Wi-Fi，手机关了就连不上 |

下面两条路都写详细了，**选一条做就行**。

## 方案 A：GitHub Pages（推荐）

### A-1 注册 GitHub

1. 打开 https://github.com/signup
2. 填邮箱、密码、用户名（用户名会成为网址的一部分，比如 `zhangsan`）
3. 验证邮箱

> 用户名建议用英文或拼音，不要用中文。

### A-2 新建仓库

1. 登录后点右上角 **`+`** → **New repository**
2. **Repository name** 填：`mingtian-chuanshenme`
3. 选 **Public**（Pages 免费版要求公开）
4. 下面的 "Add a README file" 之类的勾选项都**不用勾**
5. 点 **Create repository**

### A-3 上传项目文件

1. 在新仓库页面，点 **uploading an existing file**（或者 **Add file → Upload files**）
2. 打开你电脑上的 `明天穿什么` 文件夹，**全选里面的所有文件和文件夹**
   （`index.html`、`css`、`js`、`data`、`docs`、`tools`、`icon.svg`、`sw.js`、`manifest.webmanifest`、`README.md`、`启动本地预览.bat` —— 全都要）
3. 把它们**拖进**网页的上传区域

> ⚠️ 两个最常见的错误：
> - **不要把 `明天穿什么` 这个外层文件夹拖进去**，要拖它**里面的内容**。否则网址会变成 `.../明天穿什么/index.html`，能打开但路径容易出错。
> - 拖完后网页会列出所有文件，确认能看到 `index.html`、`css`、`js`、`data` 这几项在**列表最外层**。

4. 下面 **Commit changes** 输入框里随便写一句 `first upload`，点 **Commit changes**

> 文件多的话可能要等十几秒，别急。

#### 上传完的自检（很重要，30 秒）

回到仓库首页，看文件列表最外层，应该是 **7 个文件 + 5 个文件夹**：

```
文件：  index.html   manifest.webmanifest   sw.js   icon.svg
        README.md    启动本地预览.bat        .nojekyll

文件夹：css/   js/   data/   tools/   docs/
```

- 看到 `index.html` 在最外层 → 上传对了 ✅
- 如果最外层是一个叫「明天穿什么」的文件夹 → 拖错了，需要把里面的东西重新拖到根目录 ❌
- 少了 `js` 或 `data` → 页面会白屏，必须补齐 ❌

> `.nojekyll` 是隐藏文件，看不到也没关系；它只是让 GitHub 别用 Jekyll 处理网站，能让部署更快、更稳。

### A-4 开启 Pages

1. 在仓库页面点 **Settings**（顶部齿轮）
2. 左侧菜单往下找 **Pages**
3. **Source** 选 **Deploy from a branch**
4. **Branch** 选 `main`，右边的文件夹选 `/ (root)`
5. 点 **Save**
6. 等 1～2 分钟，刷新这个页面，顶部会出现一行：
   `Your site is live at https://你的用户名.github.io/mingtian-chuanshenme/`

### A-5 验证

用电脑浏览器打开那个网址。应该看到「明天穿什么」的引导页，问你要昵称、性别、城市。

用手机打开同一个网址，也应该正常。

**这一步就算部署完成，网址可以发给家人了。**

## 方案 B：Netlify Drop（最快，不注册也能试）

1. 电脑浏览器打开 https://app.netlify.com/drop
2. 把电脑上 `明天穿什么` **整个文件夹**拖进网页（这个方案拖整个文件夹是可以的）
3. 等它上传完，页面会给你一个网址，类似 `https://random-name-123.netlify.app`
4. 打开这个网址就能用

> 不注册的话这个网址会在一段时间后失效。想长期用：
> 页面上会让你 **Sign up**（用邮箱或 GitHub 登录，免费），登录后点 **Claim site** 把这个站点认领到自己账号下，网址就固定了。
>
> 认领后还可以在 **Site settings → Change site name** 把它改成好记的名字，比如 `mingtian-chuanshenme`。

## 部署完之后：手机怎么用相机和定位

| 功能 | 需要什么 | 不支持时会怎样 |
|---|---|---|
| 拍照 / 相册选图 | 任何环境都能用（`<input type="file">`） | —— |
| 添加到主屏幕 | **必须 HTTPS** | 只能用浏览器书签 |
| 自动定位 | **必须 HTTPS** + 用户点"允许" | 应用会自动退到"手动选城市"，不会卡住 |
| 抠图 | 要能访问 jsDelivr / img.ly 的 CDN（国内一般可以，慢的话首次要等） | 自动改用原图，流程照样走完 |

> **"非 HTTPS 定位不可用"是浏览器的安全机制，不是程序的 bug。** 用本地 `http://localhost` 或用局域网 IP 在手机上访问时，定位会被拒绝，这是正常的——选一下城市就行，天气照样能查。

## 以后改了东西怎么更新

**先说结论：要更新，但只需要传「改过的文件」，而且家人的衣橱数据不会受任何影响。**

### 为什么数据不会丢

衣橱、搭配、打卡记录都存在**每台手机自己的浏览器**里（IndexedDB），根本不在 GitHub 上。
你往 GitHub 传新版本，等于换了一份"说明书"，手机里的"衣柜"一点没动。

> ⚠️ 唯一会"看起来数据没了"的情况：**改了仓库名**，或者换成别的网址。
> 因为换了网址就是换了"门牌号"，浏览器认为这是一个全新的网站，读不到原来的数据。
> 所以仓库名定了就别再改。真要改，让家人先在「我的 → 导出备份」存一份，新网址下再导入。

### 怎么更新（三种情况，按改动大小选）

**情况 1：只改规则数字（最常见）**

比如觉得 22℃ 就该穿长袖了。可以直接在 GitHub 网页上改，不用碰电脑上的文件：

1. 仓库里点进 `data` → `rules` → `temperature.json`
2. 右上角点**铅笔图标**（Edit this file）
3. 改数字
4. 页面底部 **Commit changes** → 再点一次 **Commit changes**
5. 等 1 分钟，手机上**刷新**网页就生效了

**情况 2：改了好几个文件（我帮你改完的代码）**

1. 仓库页面点 **Add file** → **Upload files**
2. 只把**改动的那几个文件**拖进去（同名文件会被覆盖）
   - 如果改的是 `js/views/home.js`，要拖进仓库的 `js/views/` 目录里（点进对应文件夹再上传）
   - 不确定的话，**整包重传也行**：全选本地文件夹内容一起拖，同名覆盖，不会重复
3. **Commit changes**

**情况 3：只是想先在本机看看效果**

不用传 GitHub，直接双击 `启动本地预览.bat` 在电脑上看。

### 手机上没看到新版本？

这个程序的缓存策略是**网络优先**（先取最新，断网才用缓存），所以正常情况下**刷新一下就生效**，不需要改版本号。

如果确实卡着旧版：

1. 把网页**彻底关掉**（不是最小化，是从后台任务里划掉），再打开
2. 还不行 → 打开 `sw.js`，把第一行的 `v1` 改成 `v2`，提交，再刷新
3. 终极办法：手机浏览器设置里清一下这个网站的缓存（**注意：清网站数据会把衣橱也清掉**，先导出备份）

> GitHub Pages 本身有 1~2 分钟的 CDN 缓存。刚提交完没变化，先等两分钟再刷新。

## 常见问题

**Q：网址能打开了，但一片空白？**
按 F12 打开控制台看有没有红色报错。最常见的原因是：文件没有全部上传（`js/` 或 `data/` 漏了）。回仓库确认文件列表和本地文件夹一致。

**Q：手机上点了"添加到主屏幕"，图标是一块白板？**
这个版本用的是 SVG 图标，安卓 Chrome 支持，iOS Safari 可能显示默认图标。不影响使用，只是图标不好看。想换：做一张 512×512 的 PNG，命名 `icon-512.png` 放进根目录，然后在 `manifest.webmanifest` 的 `icons` 里加一条指向它。

**Q：相机打不开 / 只能选相册？**
iOS 上"拍照"是由系统接管相机 App 的，第一次会问权限。如果没反应，用"从相册选"这条路一定可用。

**Q：抠图一直转圈？**
第一次要下载模型（几十 MB），慢是正常的。界面上一直有「跳过抠图」按钮，点了立刻用原图继续，不影响保存。

**Q：家人不想用电脑，能不能给他一个包直接装？**
这个版本是网页应用（PWA），装的方式就是"用网址打开 → 添加到主屏幕"，装完和 App 一样有图标、全屏、断网也能打开。不需要应用商店。

**Q：数据会不会丢？**
数据存在各自手机的浏览器里。**清理浏览器数据 / 用无痕模式 / 卸载浏览器会丢。** 所以「我的 → 导出备份」建议每个月点一次，会存一个 JSON 文件到手机上。换手机时用「导入备份」恢复。

## 本地想再改一改、预览一下

双击 `启动本地预览.bat`，它会自己找一个能用的运行环境，按这个顺序：

1. 系统里的 `node`
2. **DeepSeek Harness 自带的 node**（就算没配 PATH 也能找到）
3. 系统里的 `python`
4. `py` 启动器
5. DeepSeek Harness 自带的 python
6. 都不行 → 用纯 PowerShell 的兜底服务器（不用装任何东西）

窗口里会打印它用的是哪一个，以及两三个 `http://192.168.x.x:8080/...` 地址。
第 1~5 种方式会监听局域网，**手机连同一个 Wi-Fi 就能打开那些地址试用**（相机、相册正常；定位会被浏览器禁用，手动选城市即可）。第 6 种方式只能本机看。

启动后电脑地址是 `http://localhost:8080/index.html`。

> 手机用局域网地址访问时**不是 HTTPS**，所以「添加到主屏幕」和自动定位用不了。想要完整体验，就按上面部署到免费托管。
>
> 第一次用兜底方式（第 6 种）时，Windows 可能弹防火墙提示，点「允许访问」，否则手机连不上。
